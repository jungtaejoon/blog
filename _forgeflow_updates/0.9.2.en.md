## New

- **Every setting on screen.** No more memorising commands: auction fee, vendor prices, tooltip prices, file export, live price codes, relay peer and the profession panel are all on the Settings page.
- **Recipe sorting.** Sort the profession list by name, by the lowest or highest skill needed to learn, by skill-up value, or with learned recipes first. One checkbox chooses between category groups and a single flat list.
- **Required skill shown.** Rows and tooltips show the minimum skill to learn a recipe and the skill at which it turns grey.
- **Panel button.** A ForgeFlow button next to the profession window's close button opens and closes the side panel.

## Fixed

- Closing the side panel with its X no longer makes it flicker back open a few times.
- English mode keeps Korean game names whole and translates common recipe categories.
