## New

- **Shared Forever recipe sources.**
  - Hovering a recipe item shows the game's "Forever sources" (vendors, drop locations, reputation and so on). ForgeFlow now records them as how to learn the recipes that item teaches.
  - The Windows app uploads them like other shared data, only with your consent, and brings back the sources other players collected.
  - Recipe items you have not hovered show Forever sources when someone else has. The more players use it, the more is covered.
- **How to learn uses Forever data first.** The one-line note in the craft-uses list shows the Forever source kinds when they are known, for example "recipe item · vendor/drop · skill 100". Only without them does it fall back to older-version data, marked "(older data)".
- **Automatic Windows app updates (0.12.5).**
  - The installed app checks the website for a new version when it opens and every 6 hours.
  - A new version, or a build with a new addon, is shown in a bar at the bottom and asked once.
  - On approval the download is checked against its published size and hash, the app and addon are replaced and the app reopens. Settings and records stay, and a failure restores the previous version.

## Good to know

- Automatic updates start with 0.12.5. If you use 0.12.4, download and install it from the website this one time.
- Sharing Forever recipe sources needs Windows app 0.12.5.

## Windows app

- **Windows app 0.12.5** (Companion 0.6.18) now installs addon 0.9.10.
