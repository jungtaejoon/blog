[alltests.ai.kr](https://alltests.ai.kr/)을 열었어요. 5급 공채·외교관, 7급 공채·민경채, 지역인재 7급 PSAT 기출을 실제 시험처럼 풀어 보는 사이트예요. Claude Code에 "기출 전부 받아서 모의고사 사이트로 운영해 줘"라고 맡기고, 중간중간 방향만 잡아 줬어요.

## 무엇이 들어 있나요

- 2005~2026년 문제지 117개, 3,915문항
- **실전 모드**: 40문항 90분 타이머, OMR 답안지, 제출하면 채점
- **연습 모드**: 문항마다 바로 채점하고 해설 보기
- **랜덤 모의고사**: 영역·시험·연도 범위를 골라 섞어 풀기 (안 푼 문제 먼저)
- **기록·오답노트**: 브라우저에 기록을 남기고 틀린 문제만 다시 풀기
- 문항마다 AI 해설: 빠른 풀이 → 근거 → 선택지별 판단 → 시간 단축 팁

## 기출을 모으는 일

기출은 인사혁신처 국가공무원 채용시스템에 공개돼 있어요. 시험은 일곱 갈래인데, 같은 날 같은 문제지를 여러 시험이 같이 쓰는 경우가 많아서 본문 글자로 지문을 떠서 중복을 걸렀더니 117개가 남았어요. 올해 파일은 전용 다운로더로만 받아져서 헤드리스 브라우저로 버튼을 눌러 받아요.

정답도 해마다 형식이 달랐어요. 최근 것은 숫자 비트마스크로, 옛날 것은 정답 팝업 HTML로, 올해 확정 정답은 PDF 정답표로만 나와서 좌표로 읽어요.

## 문항 자르기

PSAT 문제지는 2단 편집이고, 한 문항이 단이나 쪽을 넘어가기도 하고, "※ 다음 글을 읽고 물음에 답하시오. [문 25～문 26]" 같은 공통 지문도 있어요. 문항 번호 줄을 찾아 다음 번호 직전까지를 한 문항으로 자르고, 그 좌표만 저장해요. 화면에서는 pdf.js가 원본 PDF의 그 좌표만 그리니까 표와 그래프가 벡터 그대로 선명하고 용량도 작아요.

자잘한 함정이 많았어요. 페이지 맨 아래 선택지 ⑤를 쪽 번호로 잘못 알아 잘라 먹거나, 두께가 0인 빈칸 상자 테두리를 못 봐서 상자가 잘리거나, 구형 문제지는 "문"과 "1."이 다른 글자 줄이라 번호를 못 찾기도 했어요. 하나씩 고쳐서 3,915문항 모두 잘렸어요.

## 해설 3,915개

지난 기출 해설은 Claude Code 세션 안에서 썼어요. 문제지 하나에 에이전트 하나를 붙여 문항 이미지를 직접 보고 쓰게 했고, 공식 정답은 절대 바꾸지 말고 "왜 이게 정답인지"를 설명하게 했어요. 다 쓴 뒤에는 검수 스크립트가 형식, 공식 정답과 다른 번호를 주장하는 해설, 다른 문항 이야기를 하는 해설을 잡아내요. 실제로 병렬로 돌던 에이전트끼리 임시 파일 이름이 겹쳐 해설이 섞인 문제지가 두 개 나와서 다시 썼어요.

앞으로 나올 기출은 매일 새벽 GitHub Actions가 새 문제지와 확정 정답을 확인하고, 아직 해설이 없는 문항만 Claude API(Message Batches)로 써요.

## 해설을 쓰다 잡아낸 정답표 오류

재밌었던 건 해설을 쓰던 Claude가 "지문으로는 공식 정답이 설명이 안 된다"고 계속 손을 든 일이에요. 확인해 보니 2005년 정답표가 문제지 순서와 어긋나 있었어요. 언어논리는 1~20번과 21~40번 정답이 통째로 뒤바뀌어 있었고, 자료해석은 1~5번과 21~25번이 바뀌어 있었어요. 표시되지 않은 문항까지 전부 같은 규칙으로 맞아떨어져서 정답표 쪽 문제로 결론 냈어요.

2011년 민경채 언어논리 한 문항도 그랬어요. 간책형 정답표는 ①인데 지문은 ④를 가리켰어요. 민책형 정답표에서 같은 문항을 찾아보니 ④였어요. 이런 보정은 수집 스크립트에 규칙으로 남겨서 다음 자동 업데이트 때 되돌아가지 않게 했어요.

## API 키 없이 API 부르기

자동 해설에 API 키를 GitHub에 넣어 두는 대신 Claude Console의 워크로드 아이덴티티 페더레이션을 썼어요. 실행할 때마다 GitHub가 주는 OIDC 토큰을 Anthropic 단기 토큰으로 바꿔 받으니 저장된 비밀도, 만료·갱신도 없어요.

한 번 막혔던 곳이 있어요. 규칙의 subject를 `repo:소유자/저장소:ref:refs/heads/main`으로 넣었는데 인증이 거부됐어요. 이 저장소는 GitHub의 새 "immutable subject" 형식이라 subject 안에 숫자 ID가 들어가 있었어요(`repo:소유자@숫자/저장소@숫자:ref:...`). 저장소의 `actions/oidc/customization/sub` 설정을 보고 규칙을 고치니 바로 통과했어요.

## Slop 광고도 붙였어요

시험 고르는 화면과 결과 화면에만 [Slop](https://slop.ai.kr/) 자체 광고를 넣었어요. 광고도 PSAT 문항 모양이에요. "다음 중 AI가 만든 앱을 판정하는 방법으로 가장 적절한 것은?" 같은 문제를 풀면 판정하러 가는 버튼이 나와요. 시험을 푸는 화면에서는 보이지 않아요.

## 배운 점

AI에게 해설을 맡기면 틀린 해설이 가장 걱정이었는데, 공식 정답을 고정해 두고 "설명이 안 되면 숨기지 말고 손을 들라"고 하니 오히려 원본 오류를 찾아 줬어요. 의심스러운 곳을 표시하게 만드는 게 정확도를 지키는 데 제일 쓸모 있었어요.

[alltests.ai.kr](https://alltests.ai.kr/)에서 한 회 풀어 보시고, [Slop에 올린 글](https://slop.ai.kr/#/p/05501232-1492-4a45-bca5-8f87f2cc607f)에서 보석인지 슬롭인지 판정해 주세요. 코드는 [GitHub](https://github.com/jungtaejoon/psat-mock)에 있어요.
